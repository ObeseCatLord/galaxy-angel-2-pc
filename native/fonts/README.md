# UI font

`NotoSansJP-Medium.otf`: Noto Sans JP Medium (Google / Adobe, SIL Open Font
License 1.1, `OFL.txt`). A gothic close to the games' own lettering, with
Latin and Japanese, used where the port draws its own text: the launcher, the
in-game settings and cheat menus, and the high-resolution replacement glyphs
for the games' text. Shipped next to the executables by tools/package.py.
